# Synthetic Benchmark Document — Chemical Tracking System (CTS) domain

The system shall allow any user to request a container of a chemical.
The system shall notify the requestor by email when the requested chemical becomes available.
The system shall allow a user who is logged in as a Chemical Supplier to update the inventory.
The system shall reject any request for a chemical that is not listed in the approved chemical catalog.
The system shall allow the safety officer to approve or reject any new chemical before it is added to the catalog.
The system shall display the current inventory level of each chemical in real time.
The system shall generate a hazardous materials usage report upon request by an authorized user.
The system shall allow users to log in using their corporate network credentials.
The system shall send an automated reminder to the requester if a pending request has not been fulfilled within five business days.
The system shall log all chemical transactions, including the date, time, requester identity, chemical name, quantity, and location.
The system shall allow a supervisor to view all open requests submitted by members of their team.
The system shall enforce a maximum order quantity of 10 liters per request for flammable chemicals.
The system shall allow the safety officer to deactivate a chemical from the catalog without deleting its historical usage records.
The system shall provide a search function that allows users to find chemicals by name, CAS number, or hazard class.
The system shall display a warning message if a user attempts to request a quantity that exceeds the approved storage limit for their laboratory.
The system shall record the name of the approving authority for every approved chemical request.
The system shall allow a user to cancel a pending request before it has been fulfilled.
The system shall support concurrent access by at least 200 users without degradation of response time.
The system shall respond to every search query within three seconds under normal operating load.
The system shall preserve all transaction records for a minimum of seven years in compliance with federal regulations.
The system should provide a user-friendly interface for entering chemical request details.
The system should notify users of system downtime at least 24 hours in advance where possible.
The system may allow administrators to configure the email notification frequency.
The system shall integrate with the corporate LDAP directory to authenticate users.
The system shall prevent any user from viewing chemical inventory data unless they have been granted the Viewer role or higher.
